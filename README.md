# Wall Rush｜突破防線

雙人、回合制、競速與阻擋策略棋盤遊戲（同一台裝置輪流操作）。
規格依據：[Wall_Rush_V1.2_Claude_Code_開發說明書.md](Wall_Rush_V1.2_Claude_Code_開發說明書.md)。

## 規則摘要（V1.2）

- 8×8 棋盤；紅隊起點 (8,4)、目標第 1 列；藍隊起點 (1,4)、目標第 8 列。抵達目標列任一格即勝。
- 每回合二擇一：移動球一次，或放一道牆。
- 移動：上下左右一格；對手相鄰時可直線跳過（兩段格邊都無牆、落點在棋盤內），不允許側跳。
- 牆：每人 10 道，長兩格；不可出界、重疊、在中點交叉，也不可讓任一方完全無路（BFS 檢查，不把對手球當障礙）。
- 猜拳決定先手：紅先密選、換手後藍密選，各 10 秒，逾時隨機代選；兩人都選完才揭曉，平手重猜。

## Windows 開發環境

1. 安裝 [Node.js LTS](https://nodejs.org/)（開發時使用 Node 24）。
2. 在專案資料夾開啟終端機：

```bash
npm install
```

```bash
npm run dev
```

3. 開啟終端機顯示的本機網址（預設 `http://localhost:5173`）。

| 指令 | 用途 |
|---|---|
| `npm run dev` | 開發伺服器 |
| `npm run test` | 執行 Vitest 單元測試 |
| `npm run build` | TypeScript 型別檢查並建置到 `dist/` |
| `npm run preview` | 本機預覽建置結果 |

## 靜態部署

`npm run build` 後，把 `dist/` 整個資料夾放到任何靜態主機即可（已設定相對路徑 `base: './'`，可放在子目錄）。不需後端或資料庫。

## 操作方式

- 滑鼠／觸控：點亮的格子可移動（標「跳」為直線跳躍）；切到「放牆」後點選兩格之間的格線預覽，再按「確認放置」，可「旋轉」或「取消」。
- 鍵盤：`M` 移動模式、`W` 放牆模式；移動模式下方向鍵走一步；放牆模式下方向鍵移動游標、`R`／空白鍵旋轉、`Enter` 選定／確認、`Esc` 取消。

## 專案結構

```text
src/
├─ game/        純函式規則：config、edges（唯一格邊判定）、movement、pathFinding、wallRules、rps、gameRules（reducer）
├─ components/  Board、Cell、Ball、Wall、PlayerPanel、TurnIndicator
├─ screens/     Home、Rules、Rps、Game、Result
├─ tests/       Vitest 單元測試
├─ types/       共用型別
├─ sound.ts     Web Audio 合成音效（無外部音檔）
└─ styles.css
```

規則數值（棋盤大小、牆數、猜拳秒數、起點、目標列）集中在 `src/game/config.ts`。

## 安全與費用設計

- 純前端靜態網站，無後端、無資料庫、無帳號、無第三方 API、無金鑰。
- 不收集或傳送任何個人資料；唯一的本機儲存是 `localStorage` 的音效開關偏好（`wall-rush:sound`）。
- 開發時只在本機執行；若部署到公開靜態主機，公開的僅是遊戲本身，無計費服務。

## 技術預設與待確認事項

說明書第 2.2 節的技術預設皆已照實作（起點第 4 欄、一回合二擇一、猜拳平手重猜、逾時隨機代選等）。另外補充：

- **無合法行動時可略過回合**：理論上可能發生「被牆與對手球卡住、無法移動，且沒有任何合法牆位」的情形；此時才出現「略過回合」按鈕，避免對局卡死。屬技術預設，可再調整。
- **猜拳平手**：揭曉後由按鈕「重新猜拳（交給紅隊）」開啟新一輪，讓雙方有時間換手，避免紅隊倒數在交接時就開始。
- **音效**：預設開啟，只在使用者操作後播放，可隨時關閉並記住偏好。

尚待使用者決定（第 13 節）：起點是否改第 5 欄、是否加連線對戰、單回合時限、悔棋、手機視角旋轉、投降、AI 對手。
